# InkLimner v3.3.0

> 面向激光切割的黑白线稿转换器。本次更新聚焦**正确性**（手机照片方向、物理尺寸）、
> **切割实用**（裁白边 / 留白）与**工程化**（确定性输出、多进程、pip 安装、测试与 CI）。

## ✨ 亮点 / Highlights

- 📱 **EXIF 方向自动校正** —— 手机拍的照片不再横竖颠倒（`--no-exif` 可关闭）
- ✂️ **`--trim` / `--margin`** —— 自动裁掉四周白边、可留边距，切割更省料、对位更方便
- 📏 **`--dpi`** —— 比 `--px-per-mm 11.81` 直观得多的尺寸换算（`--dpi 300`）
- 🔒 **输出确定性** —— 同一输入产出逐字节一致，方便 diff 与纳入版本管理
- 🚀 **更快更稳** —— 细化算法向量化；批量多进程；失败返回非零退出码
- 📦 **可 pip 安装** —— `pip install .` 之后直接用 `inklimner` 命令

## 🆕 新增 / Added

- `--trim`：自动裁掉四周白边
- `--margin N`：成品四周补白边距
- `--dpi`：按 DPI 换算毫米（等价 `--px-per-mm dpi/25.4`）
- `--no-exif`：关闭 EXIF 方向校正
- `-j, --jobs`：批量并发进程数，并输出 `[i/n]` 进度
- EXIF Orientation 解析（JPEG APP1 / PNG eXIf），自动旋转 / 镜像
- `pyproject.toml`：支持 `pip install .` 与 `inklimner` 命令行入口
- 仓库文件：`LICENSE`、`.gitignore`、`requirements.txt`、`CHANGELOG.md`、`CONTRIBUTING.md`
- `tests/`（pytest，14 项）、`.github/workflows/`（CI + 三平台打包）、`Dockerfile`、`examples/`、`Makefile`、issue / PR 模板

## 🔧 变更 / Changed

- 内部日志改用 `logging`（`-q/--quiet` 更干净，便于库调用）
- 轮廓与线段按位置排序，输出**确定性**
- `_thin_zhang_suen` 的 A/B 计算向量化，并加入规模相关的迭代上限（纯 Python 回退更快）
- 失败时返回非零退出码（`1` 有文件失败 / `2` 参数或输入错误），便于脚本与 CI

## 🐛 修复 / Fixed

- 修复 `--px-per-mm` 与 `--max-size` 联用时的**物理尺寸偏差**（降采样自动补偿）
- 修复调色板 PNG 被误当灰度的问题（自动按彩色解码）

## 📦 安装 / Install

```bash
# 方式一：单文件
pip install opencv-python numpy
python inklimner.py --help

# 方式二：pip 安装（获得 inklimner 命令）
pip install .

# 可选：更快（细化提速约百倍）
pip install ".[fast]"        # opencv-contrib-python
# 可选：更圆滑的 shape/multi 轮廓
#   安装 potrace 1.9+

# 方式三：Docker
docker build -t inklimner .
docker run --rm -v "$PWD:/work" inklimner /work/input.png -o /work/output.svg --trim
```

## 🚀 快速体验 / Try it

```bash
python inklimner.py examples/sample.png -o out.svg --mode linedraw --trim --preview
python inklimner.py examples/sample.png -o out.svg --mode shape --trim --dpi 300
```
