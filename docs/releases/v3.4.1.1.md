# InkLimner v3.4.1.1

> 这一版给 InkLimner 装上了**图形界面**——不用敲命令，点点鼠标就能把图片变成
> 可直接切割的黑白线稿。命令行保持完整，参数两边完全一致。

## ✨ 亮点 / Highlights

- 🖥️ **全新图形界面 · 两套外观，自动选择**
  - `inklimner_gui_qt.py` —— **PySide6 现代界面**（推荐）：卡片式参数分组、圆角控件、原生拖拽
  - `inklimner_gui_tk.py` —— **Tkinter 界面**，零第三方依赖的回退方案
  - `inklimner_gui.py` —— 统一入口，有 PySide6 就用 Qt，否则自动回退 Tkinter
    （`python inklimner_gui.py --qt` / `--tk` 可强制指定）
- 🎨 **浅色 / 深色双主题** —— **默认浅色**，右上角一键切换深浅，选择自动记住；
  预览区底色、日志配色、控件状态都会同步跟随
- 📋 **日志语义化着色** —— 成功 / 提示 / 失败一眼可辨，不用逐行读
- 📦 **免安装包（云端构建）** —— 推 `v3.4.1.1` tag 即在 GitHub Actions 上自动构建
  **Windows / macOS / Linux** 三平台的可执行程序，挂到 Releases 供下载：
  `InkLimner-v3.4.1.1-windows-gui.zip`（双击即用的图形界面版）、
  `InkLimner-v3.4.1.1-windows-cli.zip`（单文件命令行版）。目标电脑**不需要装 Python**。
- 🎛️ **参数随模式联动** —— 选了 `shape`，Canny、灰带这些无关项自动置灰，只亮出真正生效的旋钮
- 📦 **参数预设** —— 内置 6 套常用配方一键套用，也能把自己调好的参数存成预设
- ⌨️ **CLI 命令互转** —— 界面设置一键导出成 `inklimner ...` 命令；也能把别人贴的命令**反向回填**到界面
- 🖱️ **拖拽导入** —— 图片、文件夹直接拖进窗口（Qt 版原生支持；Tk 版需 `inklimner[dnd]`）
- ⚡ **实时预览** —— 改参数自动重跑，所见即所得（单张小图、0.4 秒防抖）
- 🔍 **原图 / 结果对照** —— 左右并排，一眼看出调参效果
- 🧩 **双版本输出** —— 一次同时产出 `shape` 轮廓版 + 当前模式版（对应"分图层工作流"）
- 🏷️ **命名模板** —— `{name}_cut` → `图案_cut.svg`，不再覆盖源目录里的产物
- 🌡️ **环境状态条** —— 顶部直接显示 potrace 与细化后端状态
- 💾 **记忆配置** —— 窗口尺寸、上次目录、参数、自定义预设都存进 `~/.inklimner_gui.json`
- 🖥️ **高 DPI 适配** —— Windows 缩放屏下界面不再发虚
- 🖱️ **批量更顺手** —— 多选图片、或直接丢一个文件夹进去；后台线程转换不卡界面

## 🎛️ 参数联动一览

| 模式 | 额外生效的参数 |
|:--|:--|
| `linedraw` | detail · dilate · blur · min-line-len · join-gap · simplify · smooth |
| `edge` | canny-low/high · dilate · blur · min-line-len · join-gap · simplify · smooth |
| `multi` | detail · band-max · min-band · min-len · no-potrace · simplify · smooth |
| `shape` | threshold · invert · min-len · no-potrace · simplify · smooth |

尺寸/外观、预处理、输出选项这些与模式无关的参数**始终可用**。

## 🚀 用法 / Usage

```bash
# 图形界面（三种方式，任选其一）
python inklimner_gui.py       # 自动选：有 PySide6 用 Qt，否则回退 Tkinter
python inklimner.py --gui
inklimner-gui                 # pip install . 之后

# 想指定界面：python inklimner_gui.py --qt / --tk

# 命令行依旧完整可用
inklimner examples/sample.png -o out.svg --mode linedraw --trim --preview
```

可选增强依赖：

```bash
pip install "inklimner[gui]"    # PySide6：现代暗色 Qt 界面（推荐）
pip install "inklimner[tk]"     # Pillow：Tk 界面预览更清晰
pip install "inklimner[dnd]"    # tkinterdnd2：Tk 界面支持拖拽
```

> Linux 个别发行版需补系统包：`sudo apt install python3-tk`（Tk 界面）

## 🩹 修复 / Fixed

- 🧵 **线条不再莫名断开** —— 之前输出 SVG 里常出现「本应连贯的线被切成好几段」，
  这次把三个根因一起拔掉：
  1. **骨架的「对角捷径」**：1px 骨架在浅斜率处会多连一条对角边，凭空造出度=3/4 的假交叉点，
     追踪一到那里就被迫断线。现在会在构建邻接表时剔除这类冗余边。
  2. **断口补不上**：断口两端是「自由端」，旧逻辑只认「度=2 的断点」，所以永远接不起来。
     现在按**端点距离 + 方向连贯**自动拼接（平行线不会误粘），首尾可平滑相接的还会自动闭环。
  3. **过滤顺序反了**：原先先按长度过滤再拼接，被噪声切碎的长线每段都不够长 → 整条被删。
     现在改成「先补断口 → 再拼断点 → 最后才过滤毛刺」。
- 🔧 新增 **`--join-gap`**（默认 `3.0`，`0`=关闭）：断线修复阈值。**线条断开时把它调大（如 8）即可**，
  不用再手动进 Inkscape 补线。GUI 的「② 线稿参数」组里也有这一项。
- 🖱️ **修复「＋ 图片」按钮点了就报错**（`TypeError: 'bool' object is not iterable`）——
  Qt 的 `clicked` 信号会附带一个 `checked`(bool) 参数，被 `add_files(paths=None)` 误当成了
  文件列表。现在按钮统一吃掉该参数，`add_files` 也会把 bool 视作「未提供路径」，并补了回归测试。
- 📖 README（中/英）参数表、调参速查表、FAQ 都补上了断线排查指引。

## 🔧 变更 / Changed

- 抽出 `build_parser()` 与 `plan_jobs()`，CLI / GUI **共用同一套参数与输出规划**，消除逻辑漂移
- `inputs` 改为可选（`nargs='*'`），支持 `--gui` 空参启动；无输入时给出明确提示
- 跨平台打包工作流现在**同时产出 CLI 与 GUI 两个单文件可执行程序**
  （GUI 用 `--windowed` 构建，Windows 下不弹黑色控制台）
